설치

1분이면 끝나요

  1. Moveable.pkg를 엽니다

    개발자 서명이 없는 무료 앱이라 처음엔 “확인할 수 없음” 안내가 뜰 수 있어요. 그럴 땐 시스템 설정 → 개인정보 보호 및 보안 아래쪽의 그래도 열기를 누르세요.

  2. 설치를 진행합니다

    응용 프로그램 폴더에 설치되고, 끝나면 메뉴 막대에 Moveable 아이콘이 나타나요.

  3. 손쉬운 사용 권한을 켭니다

    시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Moveable을 켜면 바로 동작해요. 메뉴 막대 아이콘에 “● 동작 중”이 보이면 준비 완료.

  1. Moveable-Setup.exe를 실행합니다

    “Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행을 누르세요. 코드 서명이 없는 무료 앱이라 나오는 안내예요.

  2. 설치를 진행합니다

    관리자 권한 없이 내 계정에 설치돼요. “Windows 시작 시 자동 실행”은 원하면 체크하세요.

  3. 트레이 아이콘을 확인합니다

    작업 표시줄 오른쪽(필요하면 ^ 펼치기)에 파란 화살표 아이콘이 보이면 바로 쓸 수 있어요. 따로 권한 설정은 필요 없어요.

자주 묻는 질문

궁금한 점

다른 앱의 단축키와 겹쳐요

Moveable이 켜져 있으면 위 단축키는 다른 앱에 전달되지 않아요. macOS의 ⌥⇧ + ←/→(단어 단위 선택)나 VS Code의 Alt+Shift+방향키를 자주 쓴다면, 메뉴 막대 / 트레이 메뉴에서 크기 조절 단축키 사용을 끄세요. 창 이동은 계속 동작해요.

속도를 바꿀 수 있나요?

메뉴 막대(macOS) 또는 트레이(Windows) 아이콘을 누르면 느리게 · 보통 · 빠르게 · 아주 빠르게 4단계 중에서 고를 수 있어요.

업데이트했더니 Mac에서 동작하지 않아요

서명이 없는 앱이라 macOS는 새 버전을 다른 앱으로 인식해요. 손쉬운 사용 목록에서 Moveable을 한 번 다시 켜 주세요.

움직이지 않는 창이 있어요

전체 화면 · 최대화된 창은 움직이지 않아요. Windows에서는 관리자 권한으로 실행된 창(작업 관리자 등)도 옮길 수 없는데, 이럴 땐 Moveable을 관리자 권한으로 실행하면 돼요.

지우려면 어떻게 하나요?

macOS — 메뉴 막대에서 Moveable을 종료하고 응용 프로그램 폴더의 Moveable을 휴지통으로 옮기세요.

Windows — 설정 → 앱 → 설치된 앱에서 Moveable을 제거하세요. 자동 실행 설정도 함께 지워져요.
